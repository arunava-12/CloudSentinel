🎯 Project Objective

CodeShield demonstrates how automated security scanning can be integrated into a containerized CI/CD pipeline to detect security issues early, reduce manual security checks, and improve the security posture of applications before deployment.

🛡️ Security-First Development

Early Detection → Automated Scanning → Faster Remediation → Safer Deployment

CodeShield follows a security-first approach by integrating automated testing and security checks directly into the CI/CD workflow.
